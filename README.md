# ANPMP Conference

Client project for the **ANPMP** (Association of Nigerian Private Medical Practitioners) — a conference booking and exhibition site.

## Tech

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS 4**
- **TypeScript**

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — run production server
- `npm run lint` — run ESLint
